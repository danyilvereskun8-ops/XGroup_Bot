Legal · Server Builder Bot

Privacy Policy

Last updated: August 19, 2026

01

Overview

This Privacy Policy explains what information the Server Builder Bot ("the Bot") collects when it is added to a Discord server or used via its commands, and how that information is used. By using the Bot, you agree to the practices described here.

02

Information we collect

When the setup command is used, the Bot may process the following:

DataSource
Discord server (guild) IDAutomatically, from Discord
Discord user ID of the person running the commandAutomatically, from Discord
Server type, language choice, role names, channel names, forum counts, and voice-channel limitsManually entered by the Server Owner/Admin in the setup menus and forms

We do not collect message content, attachments, or any data from channels the Bot has not been explicitly asked to create or configure.

03

How we store this information

Currently, setup choices (server type, language, and form answers) are held only in temporary memory for the duration of the setup wizard and are discarded automatically once the server structure is created or the bot restarts — nothing is written to a database today.

We plan to introduce a database in a future update, so that the Bot can, for example, remember a server's preferred template or let admins re-run a setup with previous answers pre-filled. Once introduced, that database will store only: the guild ID, the user ID of the admin who ran the command, the chosen server type and language, and the configuration values submitted in the setup forms (role/channel names, counts, and limits). This Privacy Policy will be updated with the database provider and retention period before that feature is enabled.

04

How we use information

  • To create and configure roles, categories, channels, and forums as requested;
  • To operate, maintain, and improve the Bot;
  • Once introduced, to let a server reuse or resume a previous setup configuration.

We do not sell personal information, and we do not use collected data for advertising.

05

Data retention

In-memory setup sessions are cleared automatically once a setup completes or the Bot restarts. Any data stored in the future database will be retained only for as long as needed to provide the features described above, or until a Server Owner/Admin requests deletion (see Section 9), or until the Bot is removed from the relevant server.

06

Sharing of information

We do not share, sell, or rent collected information to third parties. Information may be disclosed only:

  • To Discord, as necessary for the Bot to operate through Discord's API;
  • To our hosting/infrastructure provider, solely to run the Bot and any future database;
  • If required to comply with a legal obligation, court order, or valid governmental request.
07

Security

We take reasonable technical measures to protect the information the Bot processes. However, no method of electronic storage or transmission is completely secure, and we cannot guarantee absolute security.

08

Children's privacy

The Bot is not directed at children and follows Discord's own minimum age requirements. We do not knowingly collect information from users who do not meet Discord's eligibility requirements.

09

Your rights

Server Owners/Admins may request access to, correction of, or deletion of data associated with their server by contacting us (Section 11). Removing the Bot from a server does not automatically delete already-created roles or channels, since those become part of the Discord server itself and are managed by Discord, not by us.

10

Third-party services

The Bot operates on top of Discord. Your use of Discord itself is governed by Discord's own Privacy Policy, which we encourage you to review.

11

Changes to this policy

We may update this Privacy Policy from time to time, particularly when the planned database feature is introduced. Material changes will be reflected by an updated "Last updated" date at the top of this page.
